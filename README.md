# NotesBridge website

Public static website (landing page, privacy policy, support) for NotesBridge, a Windows app by p2xstudio that puts iCloud Notes and Reminders on the Windows taskbar. The app source code is not in this repository.

Published with GitHub Pages from the root of the `main` branch: https://doanthaiuyen8-ops.github.io/notesbridge/

NotesBridge is an independent app and is not affiliated with, endorsed by or sponsored by Apple Inc.
